# File Sharing App

Aplikacja webowa umożliwiająca przechowywanie, przesyłanie i udostępnianie plików pomiędzy użytkownikami.

## Technologie

Java Springboot – backend aplikacji

React – frontend

## Implementowane mechanizmy bezpieczeństwa

JWT – uwierzytelnianie za pomocą tokenów.
TOTP – uwierzytelnianie dwuskładnikowe.
OAuth 2.0 – logowanie przez zewnętrznego dostawcę.
RBAC: role user/admin, enkapsulacja.

## Główne funkcjonalności

- Rejestracja i logowanie użytkowników.
- Przesyłanie i przechowywanie plików.
- Pobieranie plików.
- Udostępnianie plików innym użytkownikom.
- Kontrola dostępu do plików.
